# 现场作业人员使用手册

> **读者**：戴着手套、手上有货、站在库位前的现场作业人员。
> **不假设**你懂 Odoo、懂 AI、看过任何技术文档。
>
> 管理员/开发者的内容请另见 [`INSTALL.md`](INSTALL.md)（部署）、
> [`CONFIG.md`](CONFIG.md)（配置与扩展）、[`ACCEPTANCE.md`](ACCEPTANCE.md)（验收）。

---

## 1. 三十秒上手

1. 屏幕右上角点**对话气泡图标**（💬），打开「现场助手」。
2. 点**「免手模式」**，再点**「开启全局唤醒」** —— 图标变成 🎧 说明在听。
3. 说：**「你好助手」**。
4. 系统回你一句「已唤醒，请说指令」。
5. 直接说要做什么，或说**「下一个」**让它给你派活。

之后**全程不用碰屏幕**。要停就说**「取消」**，或再点一次「免手模式」。

> 第一次用建议先按第 2 节的**屏幕操作**跑一遍，看明白每一步在做什么，
> 再切免手 —— 两条路是同一套逻辑，随时可以来回切。

## 2. 屏幕操作（免手之前，先看这个）

打开助手后，界面上有四块内容，从上到下：

| 区域 | 用途 |
|---|---|
| **上下文横幅** | 显示你正站在哪条业务记录上（如 `stock.picking #1234`）。灰色提示「打开一条业务记录可获得完整任务上下文」时，说明还没进具体单据 |
| **语音 / 免手模式** | 两个按钮：`语音` 是按一下说一句（说完再按一下停）；`免手模式` 是全程零点击 |
| **输入区** | 条码框（扫码枪或手输后回车，旁边有 `扫码` 用相机认）、文字框（**或直接输入指令，例如：完成120件，3件不合格**）、`拍照识别` 和 `拍照留证` |
| **能力列表** | 当前场景下你能做哪些操作，以及各自的风险等级 |

输入区下面两个按钮的区别：

- **`解析指令`** —— 把你说的/写的话，变成**一件事**（识别成哪个操作、带什么参数）。
- **`编排为多步计划`** —— 把你说的/写的话，变成**一串事**（先查、再算、最后过账）。

### 说一句人话就行

不用背命令。系统会把你的话统一理解成语义，再找匹配的操作。
中英文、中英混杂都可以：

```
已清点完毕
quantity verified, all good
这批货好了 3 件不合格
```

## 2.5 拍照与扫码（必须动手机的两件事）

有兩件事**说不了** —— 拍照和扫码。没有哪句话能变出一张照片，
所以这两件事允许你动手，但动完手，系统会把你的对话原样接回去。

### 2.5.1 三个入口

| 按钮 | 干什么 | 结果去哪 |
|---|---|---|
| **`扫码`** | 打开相机，自动认条码 | 条码号填进条码框，**不自动提交** |
| **`拍照识别`** | 拍一张，把上面的文字读出来 | 识别结果填进文字框 / 数量框，**不自动提交** |
| **`拍照留证`** | 拍一张，留作这条记录的凭证 | 随这次操作一起变成记录的附件 |

三个按钮都在输入区。扫码框旁边是 `扫码`，下面一行是 `拍照识别` 和 `拍照留证`。

### 2.5.2 拍照时麦克风会停

打开相机的一瞬间，免手循环会**停下来**。这是故意的：

> 相机预览期间，麦克风听不见你说什么。你在相机前面随口说的一个「确认」，
> 不会被当成同意。

关掉相机（拍完、或按 `关闭`）之后，循环**自动接着听**，上下文和确认状态都还在原处。

所以你不需要退出免手模式，也不需要重新唤醒一次。

### 2.5.3 照片会怎样

拍完的照片：

1. **会上传**，用于识别（`拍照识别` 时）；
2. **会作为附件留在业务记录上**（`拍照留证`、或引导流程里的留证步骤）；
3. 在界面上会显示成一个小标签，写着 `照片 1`、`照片 2`，点后面的 `×` 可以删掉重拍。

> 拍之前界面上会写一句：**照片会上传用于识别，并作为记录附件留存。**
> 如果这台设备或这个场景不允许上传照片，就不要拍。

### 2.5.4 识别出来的东西，要你自己确认

这一条最重要：

> **识别结果只填进输入框，绝不会自己提交。**

也就是说：

- 拍标签认出了数量 → 数字填进**数量框**，你按 `确认数量` 才算数；
- 拍照认出了条码 → 填进**条码框**，你按回车才去查；
- 拍糊了、认错了 → 框里等你改，不会有一个错误的数字被直接写进库存。

认不出来时，屏幕上会说「没能识别出内容，请重拍或直接输入」，**不会**塞一个 0 或者乱码进去。

### 2.5.5 设备不好使的时候

| 情况 | 会怎样 |
|---|---|
| 不给相机权限 / 没有相机 | 提示「无法访问相机，请改用相册或手输」，**手输照常用** |
| 浏览器不会自动认条码 | 提示「此浏览器不能自动识别条码，请对准后拍照，或直接输入」 |
| iPhone 上相机打不开 | 用 `相册` 按钮（调系统相机），这条路一定能走 |
| 想拍一张别人帮你拍的照片 | 同上，走 `相册` |

**结论：设备再差，条码也能手输、说明也能打字，工作不会卡住。**

## 3. 免手模式（重点）

### 3.1 为什么要有「唤醒词」

因为麦克风要**常开**才能免手，但常开不等于什么都上传。

> **唤醒词之前的音频，只在手机内存里比对，然后立刻丢弃 —— 不上传、不落盘、不保留。**
> 只有听到「你好助手」**之后**的那句话，才会送去转写。

这就是要设唤醒词、而不是让录音一直开着的原因。

### 3.2 唤醒词

下面任一句都能唤醒（大小写、标点无所谓）：

| 中文 | 英文 |
|---|---|
| 你好助手 | hey assistant |
| 嗨助手 | hi assistant |
| 助手 | assistant |

> 「助手」两个字就够，但现场嘈杂时建议说全**「你好助手」**，误唤醒更少。

### 3.3 说完不用按停止

系统靠**声音大小 + 停顿时间**自动判断你说完了（约 0.8 秒不吭声就算说完）。
所以中间**不要停顿太久**，一句话最好连贯说完。

系统自己在播报时**不会听你说话**（否则会把自己的声音当成你说的），
播报结束会自动恢复 —— 这是正常的，不是卡住。

### 3.4 界面上的小字条

开着免手时，界面上会出现两行：

- **状态徽章** —— `idle` / `listening` / `capturing` / `thinking` / `speaking`，一眼看出它在干嘛。
- **🔊 上一句** —— 显示它刚才**听到/播报了**什么。**这是免手时你唯一能核对的凭据**，
  瞄一眼就能确认它没听错。

## 4. 完整免手：五个界面都行

免手不只是"说话代替打字"，还要能推进流程。下面四处以前都要动手，现在都能说。

### 4.1 打开界面（全局唤醒）

面板只在**打开时**才存在，所以它自己没法成为"把它打开"的东西。
**全局唤醒监听挂在右上角的托盘图标上**，整个会话都在。

- 点托盘里的 **`开启全局唤醒`**，图标旁会出现 🎧，表示**在后台待命**。
- 之后即使面板是关的，说**「你好助手」**也能把助手叫出来。
- **这个后台监听只负责"打开界面"，不会执行任何业务操作** —— 它只能叫醒，不能动手。

### 4.2 语音引导（一步步带你做）

选流程 → `开始`。每步会播报，并告诉你要做什么。

| 步骤类型 | 你要做的 |
|---|---|
| 核对类 | 说**「确认」**或**「到达，下一步」**进入下一步 |
| 扫码类 | 扫码枪扫，或**说条码** |
| 数量类 | **说数量**（「一百二十」或「120」都行） |
| 执行类（高风险） | 会先问一遍，说**「确认」**才真执行 |

流程中新手上手更快：**新手模式**步骤更细、有讲解和期望值复核；
**熟手模式**合并步骤、播报精简、节奏更快。随时可切，进度不丢。

### 4.3 任务循环（它给你派活）

这是最适合"边走边干"的用法：

1. 说 **「下一个」** —— 系统派一个任务给你，并播报**为什么选这个**。
2. 干完活，**直接说干了什么** —— 比如「已清点完毕」「数量对上了」。
   > **把做了什么说出来，就是汇报。** 不用先说"汇报"，再说内容。
3. 如果这一步是高风险操作，系统会问一遍，你说**「确认」**过账。

界面上的**「智能体建议」**那张卡会告诉你：

- **`智能体自主判断`** 徽章 = 模型真的想过，还会给**置信度**和**理由**；
- **`队列兜底`** 徽章 = 模型没连上，按优先级队列发的任务，理由会说清楚；
- **「其他候选（N）」** 展开能看到**为什么没选那几个**。

> 系统**不会**把兜底伪装成"深思熟虑的决定" —— 徽章一眼就能分辨。

### 4.4 智能体循环（让它自己往下走）

点**`启动智能体`**，之后由服务端决定下一步。界面上会显示：

- **本步决策** —— 它想干什么、为什么（`why`）、动哪条记录、带什么参数；
- **预算** —— 还剩几轮、还能调几次能力，**到顶会停并告诉你**，不会突然卡住；
- **决策轨迹** —— 展开能看到每一步的取舍，灰色行 = 不是模型决定的。

**它是在想，不是在背脚本。** 智能体看的是你的**任务目标**、记录的**当前实况**
（比如库存数、单据状态）和**上一步的结果**，然后自己判断下一步该做什么。
流程模板只是"这个岗位通常怎么做"的**参考**——它可以基于实况跳过某步、
换个顺序，或者发现"这一步其实已经完成了，不用再报数"。你不需要按着
屏幕上的步骤清单一步步喂给它。

**一次任务 = 一场对话。** 从取任务到汇报完成，智能体全程记得你们这个任务里
发生过什么（做过哪些动作、结果如何）。任务一完成（或你放弃/换任务），这场
对话就**结束并清零** —— 下一个任务是全新的一场，它不会把上一个任务的
印象带过来。所以：**换任务后请重新 `启动智能体`**，旧界面上的"继续"按钮
对已结束的任务不起作用（系统会提示重新开始，而不是悄悄续跑别的任务）。

到了要动手的地方，界面会变成两种问题之一：

| 它问什么 | 你怎么答 |
|---|---|
| **要你确认**（高风险写入） | 说**「确认」**；不想做就说**「取消」** |
| **问你一个问题** | **有选项按钮就照着念选项文字**；没有就自由说 |

> **选项只能照念。** 界面给出的选项是服务端认的答案集合，
> 你说选项的文字，系统发出去的是那个选项的**代码**（和点按钮完全一样）。
> 这样做是为了防止"随便说个别的"绕过场景白名单。

### 4.5 系统的求助

任何界面都能问「怎么办」「这个库位在哪」「how many should I enter?」。

## 5. 语音指令速查表

### 5.1 确认与取消（最重要）

| 说什么 | 效果 |
|---|---|
| **确认** / 确定 / 执行 / confirm / yes / ok | 放行**已经暂存的那一笔**高风险操作 |
| **取消** / 放弃 / 不 / cancel / no / stop | 放弃待确认的操作 |

> ⚠️ **三条安全规则，请务必知道：**
>
> 1. **必须整句就是那个词。** 说「别确认」**不会**执行 —— 它听得出你是在否定。
> 2. **只有真有操作等着确认时才管用。** 平时说「确认」只是普通说话，
>    不会提前批准后面的步骤。
> 3. **确认框一关就失效。** 完成、失败、取消之后，再说「确认」不会重复执行。

### 5.2 导航指令

指令**只在对应界面有效** —— 在拣货引导里说「跳过」有用，
在助手面板里说「跳过」不会有反应（因为那里没有"下一步"可跳）。

| 指令 | 可说的地方 | 说法 |
|---|---|---|
| 下一个任务 | 任务循环 | 下一个 / 下一个任务 / 继续 / next |
| 求 助 | 任务循环 / 语音引导 / 智能体 | 怎么办 / 帮助 / 怎么弄 / 怎么做 / help / how |
| 跳过 | 语音引导 / 智能体 | 跳过 / 略过 / skip |
| 再说一次 | 全部界面 | 再说一次 / 重复 / 再念一遍 / repeat / again |

> 同样是**整句匹配**：「下一步是什么」是**问题**，不会让流程往下走。

### 5.3 说的词 ↔ 屏幕上的按钮

语音和点击是**同一套逻辑**，下面这些一一对应，效果完全一样：

| 你说 | 等于点这个按钮 |
|---|---|
| 确认 / 确定 | **`确认执行`** |
| 取消 / 放弃 | **`取消`** |
| 下一个 | **`获取任务`** |
| 跳过 | **`跳过`** |
| 再说一次 | （重播当前播报） |

> 界面上按钮写的是「确认**执行**」，但你**只需要说「确认」**两个字。

### 5.4 没有听懂时

系统会说「没有听懂，请再说一次」。**换个短一点的说法**通常就好了。

## 6. 风险等级：什么时候会拦你

每个操作都有等级，界面上的能力列表和各处徽章都会显示：

| 等级 | 含义 | 要不要确认 |
|---|---|---|
| **L0** | 查询 —— 只看不动 | 不用 |
| **L1** | 低风险写入 —— 加备注、记一条 | 不用 |
| **L2** | 业务状态变更 —— 过账、报工、验单 | **要** |
| **L3** | 高风险 | **要**，且需管理员额外开启 |

**L2 及以上的操作，一定会停下来问你**，无论屏幕点还是语音说。
确认框会告诉你三件事：**做什么**（action）、**动哪条**（对象）、**什么后果**（影响）。

### 四个结果，含义不同

| 结果 | 界面颜色 | 意思 | 你该做什么 |
|---|---|---|---|
| **成功** | 绿 | 做完了，已核对 | 继续 |
| **失败** | 红 | 没做成，**没留下半成品** | 看提示改一下重试 |
| **结果未知** | 黄 | **不确定到底成没成** | ⚠️ **先去业务单据上亲眼核对，不要直接重试** |
| 已取消 | 灰 | 你取消了 | 继续 |

> **「结果未知」为什么单列一档**：网络断了、超时了，可能已经执行也可能没执行。
> 直接重试可能**做两遍**（比如过账两次）。所以它会明确拦住你，
> 让你先去单据上看一眼实际状态。

## 7. 四大场景做什么

| 场景 | 适用 | 引导流程 | 典型操作 |
|---|---|---|---|
| **仓库** | 收货、拣货、盘点 | 语音引导拣货 `wh_guided_picking` | 查库存、报告数量、验证单据、应用盘点、拍证据 |
| **制造** | 工单、报工、设备异常 | 语音引导工单作业 `mfg_guided_workorder` | 查下道工序、报工、报设备故障 |
| **现场服务** | 上门维修、保养 | 语音引导现场服务 `fs_guided_service` | 识别设备、查维修史、记报告、记备件、拍照、完工 |
| **销售拜访** | 客户拜访 | 语音引导客户拜访 `sales_guided_visit` | 查客户历史、记拜访记录、更新线索、约跟进、建报价单 |

正在做的操作叫什么、属于哪个场景、要不要确认，界面上都会写清楚。

## 8. 常见问题

**说「你好助手」没反应？**
图标旁没有 🎧 就是没在听。重新点 `开启全局唤醒`。也检查一下浏览器有没有麦克风权限
（地址栏左边的小锁点开看）。

**它听错了我说的？**
看一眼界面上的 **🔊 上一句** 就能确认它听到的是什么。
说「再说一次」让它重播，或者换个更短的说法。

**我说话了但它不接？**
它自己正在播报时**是听不见的**（故意的，防止把自己的声音录进去）。
等它播完再说。

**每句都自动断句，我说一半就被打断了？**
中间停顿别超过约 1 秒。长句请连着说。

**没有麦克风 / 浏览器不支持？**
会明确提示「此设备不支持免手模式，请使用屏幕操作」。
**所有屏幕操作原样保留**，功能一样不缺。

**高风险操作太多，每次都要说「确认」？**
这是设计如此，也是没法关的。过账、验单这类操作一旦点错，
改回来要开的单据比说一个「确认」麻烦得多。

**旁边有人听到并模仿我的「确认」怎么办？**
> ⚠️ **真实残留风险，请认真对待。** 声音可以被旁人模仿，噪音也可能误识别。
> 如果现场有他人可能听到并复述你的话，**对 L2 操作请改用屏幕点确认** ——
> 点击路径从来没有被移除。

**转写/识别服务不可用？**
会提示「识别服务不可用，请再说一次」或「转写不可用，请改用文字输入」。
**改成打字/点屏幕就行**，流程不受影响。

**换了任务，智能体怎么像"失忆"了？**
这是故意的：**一个任务 = 一场对话**。上一个任务的对话在任务完成或放弃时就
结束了，新任务从空白开始 —— 它不该把上一单的印象带进这一单（库存可能早变了）。
点 `启动智能体` 重新开场即可；你个人的熟手/新手偏好会保留。

**同一个任务刷新页面，智能体还记得吗？**
记得。只要还是**同一个任务**，进度存在服务器上，刷新、切页面再回来都能接着走。

## 9. 一页速记

```
唤醒            你好助手
取任务          下一个
汇报            直接说「干了什么」        ← 不用先说"汇报"
答题            有选项就照念选项文字
放行高风险      确认
放弃            取消
重播            再说一次
求助            怎么办
```

**四条必须记住的：**

1. **唤醒词之前的音频不上传**，只比对后丢弃。
2. **「确认」必须整句、且真有操作待确认时才有效** —— 「别确认」不是同意。
3. **看到「结果未知」先去单据核对，别直接重试。**
4. **拍照和扫码要动手，但识别结果只填框、不提交** —— 最后按下去的那一下永远是你。
